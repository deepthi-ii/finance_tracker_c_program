RupeeSense is a personal finance management web application designed to help users manage their income, expenses, savings goals, and shared expenses.



The project uses C Programming as its primary backend programming language, along with HTML/CSS-based web presentation and supporting technologies.

Main Features

User Authentication: Sign up and sign in using Supabase authentication.

Personal Dashboard: View income, expenses, and available balance.

Transaction Management: Add and manage personal financial transactions.

Savings Goals: Create and track savings goals.

Shared Expense Management: Create shared rooms and manage group expenses.

Room Invitations: Join shared expense rooms using invitation codes.

Expense Splitting: Divide shared expenses equally among participants.
